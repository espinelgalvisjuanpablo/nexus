                    Arquitectura del Sistema & Protocolos
                

            

            

                Documentación detallada sobre el stack tecnológico, patrones de diseño, renderizado en cliente y ciclo de purga de datos.
            

        


        

            

                

                    

                        
                    

                    

                        
01. Arquitectura Frontend & SPA Engine

                        Single Page Application Vanilla ES6+
                    

                

                

                    Construido bajo un paradigma de Single Page Application (SPA) puro, sin sobrecarga de frameworks pesados (Zero-Dependency Design). Todo el enrutamiento y la actualización de vistas se gestionan dinámicamente mediante manipulación directa del DOM en JavaScript ES6+.
                

                

                    
• Paradigm: Client-Side SPA

                    
• Core: Vanilla JavaScript ES6+

                    
• Latency: < 200ms TTFB

                    
• Dependencies: Modular CDN-linked

                

            


            

                

                    

                        
                    

                    

                        
02. Ciclo de Purga & Retención a 30 Días

                        Automated Data Purge & Garbage Collection
                    

                

                

                    El sistema implementa una política de ciclo de vida automatizado de retención de datos de 30 días. Los registros cuyas marcas de tiempo superen los 30 días naturales son purgados automáticamente mediante Garbage Collection para optimizar memoria.
                

                

                    
• Retention: 30 Rolling Days

                    
• Purge Logic: Cron-like Filter

                    
• Memory Mgmt: Auto GC / Array Shift

                    
• Data Integrity: ISO-8601 Verification

                

            


            

                

                    

                        
                    

                    

                        
03. Consumo Asíncrono & Renderizado Canvas

                        REST APIs & 60FPS Animation Canvas
                    

                

                

                    Consumo de servicios externos mediante la API Fetch nativa con promesas asíncronas (async/await) y manejo de excepciones. La sección Hero integra una simulación física vectorizada ejecutada a 60 FPS mediante Canvas 2D.
                

                

                    
• API Transport: Fetch API (REST)

                    
• Canvas FPS: 60 FPS Loop

                    
• Vector Icons: Lucide SVG Engine

                    
• Failover: Cached Fallback

                

            


            

                

                    

                        
                    

                    

                        
04. Sistema UI/UX & Persistencia Local

                        Tailwind Utility-First & Client PDF Engine
                    

                

                

                    Interfaz responsiva con Tailwind CSS. Las preferencias del usuario (idioma y modo visual claro/oscuro) persisten localmente en la Web Storage API (localStorage).
                

                

                    
• Styling: Tailwind Utility Engine

                    
• Persistence: Web LocalStorage API

                    
• PDF Compiler: Client-Side jsPDF

                    
• Typography: Plus Jakarta + JetBrains
